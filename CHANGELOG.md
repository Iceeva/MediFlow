# Changelog

## 0.1.0 - initial release

- Phase 1: Next.js 15, TypeScript strict, Prisma schema, PostgreSQL, Vercel configuration
- Phase 2: sessions, registration and login, password reset, email verification, RBAC, tenants and users
- Phase 3: patients (scoped access, archive, export), doctors (availability), staff
- Phase 4: appointments with conflict detection and calendar
- Phase 5: consultations, vitals, medical history
- Phase 6: medications and prescriptions with PDF
- Phase 7: StorageService (Vercel Blob, S3, R2), validated uploads, signed downloads
- Phase 8: invoices with PDF, payments (idempotent), signed Stripe webhook
- Phase 9: notifications, Resend emails, Vercel Cron reminders
- Phase 10: role based dashboards, analytics, global search
- Phase 11: audit log API, security headers, rate limiting
- Phase 12: unit, component and database integration tests
- Phase 13: Docker (development) and GitHub Actions
- Phase 14: documentation and deployment guide

Not implemented: TOTP 2FA, antivirus scanning, Mobile Money and bank payment providers, refunds.
